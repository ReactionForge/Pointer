# 1.3.0-beta.4 验收记录

本版本针对 beta.3 安装后的动效、更新检查、关闭提示、调节控件、性能及快捷方式图标问题增量修复。保留用户认可的 Material 界面、导航、圆角、配色、固定操作条与原始圆润动效。开发分支为 DEV，使用新的 `v1.3.0-beta.4` 预发行标签；不合并 main，不替换 v1.1.1 稳定版。

## 修复与交互

- **应用后动效**：原界面应用配置使用保留后台状态的路径，已暂停的服务会继续暂停。显式“应用更改”现在启动服务并等待就绪，再显示成功；后台错误不再被状态快照覆盖。状态区区分启动、运行、暂停、全屏免打扰及故障。原始动效计算与像素资源保持不变。
- **更新检查**：后台 Python 线程没有 Qt 事件循环，原单次定时回调无法可靠送到界面。改为界面线程信号、10 秒界面截止、请求合并及迟到结果丢弃。网络有独立期限、页数和响应大小上限。预发行用户能够发现后续 beta；稳定版只检查稳定通道。下载关闭或 Escape 可取消，不阻塞界面退出，升级准备失败会阻止启动安装器。
- **关闭提示**：侧栏保存与光标应用原有两个草稿，但底部只表示光标状态。现在侧栏修改显示“外观待保存／保存外观”，两者均有修改显示“保存并应用”；取消和恢复已保存值同步清除状态。外观保存失败保留草稿并阻止后续应用。真正未保存的修改仍需确认，未修改关闭直接退出。
- **调节与重置**：动效强度、按下／松开时间和测试灰度使用 3 DIP 细轨道、16 DIP 圆点、28 × 28 DIP 命中区域，提供带单位的数值输入、焦点及键盘操作。滚轮经过控件只滚动页面。动效重置只恢复动效参数，灰度重置仅影响测试；全局“重置默认参数”保留启动、托盘及更新偏好，先进入草稿。
- **文字**：造型名称使用独立固定行、明确的字体与字重，保持图形和文字对齐；更新异常长文本允许换行并保留完整提示，避免窄窗水平溢出。
- **图标**：beta.3 EXE 已含正确的七种尺寸图标，检查发现快捷方式未明确指定图标。新版本的安装和 ZIP 快捷方式显式绑定 `pointer.ico,0`，应用设置 QApplication 图标。安装成功后仅通知 Shell 刷新 Pointer 自己的图标和快捷方式；不清除 Windows 全局图标缓存。构建逐帧核对 EXE 的 RT_ICON 与既有 ICO 一致。自定义部署仍在原 `ssPostInstall` 时点，不提前改变安装事务边界。

## 性能证据

透明度、模糊和窗口激活变化改为更新背景与有关控件，避免重设整窗样式。后台轮询使用轻量服务状态，不再每秒读取全量注册表和配置快照。预览不因相同参数重置动效时钟，保留有界帧缓存；空闲、隐藏及减少动效状态停止无意义定时器，加载光标保留原始节奏。

资源预热只保留最新草稿，延迟到短暂空闲后在独立进程生成；不在启动时推测生成全部配色。内部资源生成入口不创建 Application、不迁移配置、不读写注册表或操作服务。Windows Job Object 限制和回收本次生成的进程树，超时清理不会结束用户的其它进程。

| 本机测量 | 修改前 | 修改后 |
| --- | --- | --- |
| 同一隔离窗口连续 20 次侧栏参数变化，中位耗时 | 349.38 ms | 6.64 ms |
| 同一非内置配置冷生成期间，5 ms 界面心跳的最大间隔 | 181.56 ms | 19.41 ms |
| 独立进程生成期间，界面进程 CPU 时间 | 未使用独立进程 | 0.094 s |

这些是本机指定场景的测量，不是所有电脑的帧率保证。冷生成仍需要约 11 秒，界面可以继续交互；首次应用若资源未就绪，仍会等待必要的生成与服务握手。

## 继承验证与剩余限制

本轮未改变 Windows Composition 背景组件。既有 v4 实机记录已在同一 alpha 140、同一窗口几何下比较 Gaussian 模糊 10 与 48，并验证背后真实窗口移动时背景实时变化，前景文字清晰；详见 [背景迭代记录](../design/material-window-iteration.md)。Windows 10/11 x64 可运行；真正的 host backdrop 要求受支持的 Windows 11。关闭效果、不支持、高对比、系统关闭透明效果及窗口失活使用回退，不修改全局设置。

本版本可作为后续商业迭代的预发行应用与源码基线，仍不是完成全部商业发行验收的稳定版本。用户机器上新安装桌面图标显示、真实系统光标按下效果、混合 DPI／跨屏／Snap、真实高对比切换及长时间 GPU／功耗表现仍需实机验收。原生窗口拖动和最大化还原继承此前 beta.3 记录，本轮没有重复取得有效完整实测。发布包未代码签名，未新增依赖或本地工具。
