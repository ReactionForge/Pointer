# 主分支发布与推广交付记录

## 范围与版本

维护者明确请求发布并合并主分支。本轮基于已满意的 DEV／v1.3.0-beta.6 提交 `786d71c4b54ef9181e3e4f1bc336235e523b0aca`，不改变应用源码、光标资源或版本号，不移动历史标签，不覆盖原 EXE／ZIP。main 同步当前功能基线；后续开发仍在 DEV。

本轮新增中英文介绍、使用／支持／贡献／安全指南、商业化条件、推广文案、当前 MaterialWindow 截图、自动视频制作及公开文档检查。Windows CI 同时覆盖 main 和 DEV。原 [beta.6 验收记录](<1.3.0-beta.6.md>) 中“不合并 main”描述的是原发布时点；本次合并是随后收到维护者明确发布请求的新操作，不重写历史记录。

追加捕获回归曾与现有长生命周期 Qt 测试处于同一进程，一次全套复验出现窗口包装对象类型异常（396 项，1 error）；没有改动产品代码或削弱原拖动断言。将捕获回归隔离到独立进程后，新增回归与原拖动检查联合通过，再执行完整复验。视频制作始终在独立进程执行。

源码测试中的条件跳过来自未显式设置打包集成目录，以及 Windows 符号链接权限条件。打包集成随后单独开启并通过；不为绕过符号链接测试而修改系统权限。测试日志、下载包及私人工具位于被忽略的本地目录，不随源码发布。

原基线的 GitHub [Windows 构建、诊断与安装器检查](https://github.com/ReactionForge/Pointer/actions/runs/37636725852) 已成功；这只是原功能基线证据，不替代新增提交的 CI。
