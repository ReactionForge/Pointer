# 1.3.0-beta.2 验收记录

本版本将已认可的 Material 工作台接入正式桌面入口，在原实现上增量调整，保留此前设计记录和发行包。开发分支为 DEV，标签为 `v1.3.0-beta.2`；使用预发行通道，不合并 main、不替换 v1.1.1 稳定版。

## 最后两处控件

- 透明度与模糊滑轨使用 3 DIP 细轨道和小圆点，拖动命中区域仍为 28 × 28 DIP。深浅主题、禁用状态与键盘焦点分别绘制，数值输入和滑轨双向同步，滚轮经过控件不会修改参数。
- 窗口主题使用浅色／深色分段选择，明确显示当前状态，提供太阳／月亮图标。支持 Tab、方向键、Home/End、Enter/Space；重复选择当前主题不产生修改。

外观保存与系统光标“应用更改”保持独立，测试和窗口主题切换不隐式应用光标。

## 新包验证

本地使用现有构建环境生成了本版本的新冻结 EXE 和 ZIP，没有安装工具。背景组件编译后随包交付；运行冻结 EXE 不调用本机编译器。安装 EXE 由现有 GitHub Windows 工作流构建，只有测试、打包诊断、隔离安装／升级／卸载和安装器检查全部成功，标签流程才发布。

## 桌面合成与限制

背景实现使用 Windows Composition host backdrop 与 Gaussian；只绘制侧栏背景，Qt 文字／图标及右侧内容保持独立。此次发布前 v4 实机验证已比较同一 alpha 140、同一窗口几何下的模糊 10 与 48，并验证固定参数时背后真实窗口移动会改变背景；内部渲染图只用于布局，没有作为桌面合成证据。相关原始记录保留在 [v4 迭代记录](../design/material-window-iteration.md)。最新两处控件的验收另使用本版本的新 EXE。

Windows 10/11 x64 可以运行；真正的 host backdrop 要求受支持的 Windows 11 环境。不支持、高对比、系统关闭透明效果、窗口失活或组件错误时使用回退，保留已保存参数，不修改 Windows 全局设置。

混合 DPI、跨屏、Snap、真实系统高对比切换及长时间 GPU／功耗表现尚未完成实机验收。系统策略回退采用注入策略测试；未实际更换系统光标。发布包未代码签名。
