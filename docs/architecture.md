# Pointer 架构

## 分层职责

- `bootstrap.py` 在导入 Windows 模块前解析数据与安装目录覆盖参数；`paths.py` 分离程序资源、持久安装目录和用户数据。
- `cli.py` 分发 GUI、后台、诊断、安装、暂停、恢复和升级命令。无参数打开 APP；后台命令先于任何 GUI 导入返回。
- `application.py` 管理配置事务：校验 → 准备资源 → 停服务 → 保存配置与资源索引 → 应用系统方案 → 独立更新启动选择 → 启动并确认就绪。失败恢复文件、系统方案和之前的运行状态。
- `cursor/settings.py` 管理严格校验、版本化 JSON、旧动效迁移、原子保存与导入导出。`cursor/resources.py` 共用绘图和缓存生成；缓存损坏时重建，保留旧资源与用户文件。
- `cursor/art/` 是唯一绘图实现。`motion.py` 管理按下、保持和松开阶段；大小、配色和强度在应用配置时预先生成。
- `windows/engine.py` 仅运行本机背景识别、系统光标切换与左键状态采样。每轮不绘图、不写启动项、不访问网络。后台与 GUI 分离，退出 GUI 不停止效果。
- `windows/scheme.py` 保存最初光标备份并可恢复系统设置；`startup.py` 只更新真正变化的当前用户启动项；`installation.py` 管理验证清单、迁移、完整部署与回滚。
- `windows/gui_ipc.py` 管理 GUI 单实例、激活及升级关闭请求。有未应用草稿或操作未完成时中止升级；过期请求不影响下次打开。
- `ui/` 拥有已应用配置与草稿，工作线程通过信号返回结果。四个页面只调用应用层，不直接修改注册表；暂停与恢复运行保留未应用的草稿。

## 预览与系统测试

右侧预览使用草稿和共用绘图实现。测试页使用真实 Windows 共享系统光标句柄，拦截自有测试控件的光标请求；不复制句柄，也不画跟随鼠标的替身。

普通箭头和链接小手可形变，输入、等待及其余角色保留当前造型。所有形变帧保留相同热点并留透明边距。多分辨率 CUR 栅格最大为 256；更高物理尺寸由 Windows 缩放。ANI 每帧存最高分辨率的单张 CUR，避免 Windows 拒绝某些多分辨率组合。

后台按窗口 DPI 选择物理画布。自动模式使用 112/144 亮度阈值和稳定时间抑制抖动；固定模式保持选定配色。状态由互斥量与启动就绪标识确认，不只信任遗留状态文件。

## 程序与数据

默认发布程序目录是 `%LOCALAPPDATA%\Pointer\app`；用户数据是相邻 `data`。部署时生成经过严格验证的 `INSTALLATION.json`，使自选目录、快捷方式和登录启动都能从自身位置确定相同的数据目录，适应 Windows 商店宿主的 AppData 重定向。源码默认使用仓库 `.local/data`。隔离参数在入口导入前生效，并传播到后台。

数据包括 `settings.json`、`active-profile.json`、光标缓存、运行状态、原始光标和启动项备份。导出文件只有设置与格式版本。程序清单不包含这些个人数据。

## 安装、升级和卸载

安装器按当前用户工作，无需管理员权限。载荷先进入临时目录，再由同一部署实现校验、准备完整目录、停止旧实例并切换；保留旧目录直至后续快捷方式、启动设置与恢复服务全部成功，失败恢复旧文件、配置及运行状态。升级保留用户文件与数据；迁移也识别已验证安装所属的自定义缓存光标。

便携版可直接打开预览。首次应用将运行文件部署到持久安装目录，并通过已安装程序应用设置。卸载先恢复原光标和关闭本 APP 启动项；失败中止删除。程序退出后，卸载器只删除散列仍与清单一致的程序文件，保留修改过的文件和用户新增文件。用户设置默认保留，可选择清除自定义设置，原光标备份仍保留。

## 验证与发布

`tests/unit` 对真实文件与原生加载进行检查，系统写入必须替换为受控测试边界。`tests/integration` 显式指定发布包后，在临时目录验证安装、升级和卸载准备。`scripts/smoke_installer.py` 验证真实安装 EXE 的完整生命周期。

`VERSION` 是发布版本唯一来源，允许 `1.3.0-beta.1`；Windows 数值版本为 `(1,3,0,0)`。GitHub Windows 运行器提供安装编译器，DEV 构建通过后再发布预览版，不合并 main 或替换稳定版。
