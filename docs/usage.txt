Pointer 桌面 APP 使用说明

桌面预览版下载：https://github.com/ReactionForge/Pointer/releases/tag/v1.3.0-beta.5

安装 EXE，或完整解压 ZIP 后双击 Pointer.exe。
Windows 10/11 x64，无需 Python、管理员权限或联网。

光标外观：选择自动适应或固定配色；分别调整浅/深背景的主体和边框颜色，设置大小。
左键动效：选择整体倾斜、缩小回弹或关闭；调整强度、按下时间和松开时间。
右侧显示未应用草稿。点击“应用更改”后改变 Windows 光标；取消修改恢复当前配置。

界面支持浅色/深色选择。侧栏透明度与背景模糊独立，可拖动滑轨或直接输入数值，回车或离开输入框后预览。
“保存外观”记忆参数并在重启后恢复；“取消预览”恢复上次保存值。透明度按主题分别记忆。
背景组件已随包提供，不需要编译器。真正的 host backdrop 模糊要求受支持的 Windows 11；Windows 10 或合成不支持时回退。
高对比、系统关闭透明效果及窗口失活时使用回退；程序不会修改 Windows 全局透明或高对比设置。

浅色背景默认黑色主体、白色边框；深色背景默认白色主体、黑色边框。圆角造型，无蓝光。
默认箭头整体向左下倾斜 6°，顶部明显移动、下面两尖轻微跟随；小手倾斜 12°。
长按保持，松开 150 ms 回正。点击热点始终固定。

光标测试：用真实鼠标测试黑白交界、亮度滑块、灰度、小手按钮、文字输入、拖动、等待和各缩放角色。
等待只影响指定区域，离开即结束。点击次数只证明事件接收，外观与动效请实际观察。

应用设置：开机启动由你选择。暂停光标效果不会取消开机启动。
关闭设置界面后后台继续运行。导入 JSON 更新草稿，应用后才生效；导出不包含机器路径或系统备份。
“恢复 Windows 原光标”会停止效果并关闭 Pointer 开机启动，保留自定义配置。

升级：运行新安装包，已有设置与最初原光标备份保留。
有未应用草稿时，请先应用或放弃再升级。卸载前恢复原光标，恢复失败会中止卸载。
卸载默认保留配置，保留修改过的程序文件和新增用户文件。

程序目录：%LOCALAPPDATA%\Pointer\app；配置与备份：相邻 data 目录。
商店应用宿主可能重定向该路径。ZIP 首次应用会部署到持久目录，成功后可删除解压目录。

APP 测试使用系统光标。Windows“照片”的拖动手掌及其他软件自绘的光标可能来自软件自身资源。
文本插入时闪烁的细竖线也由软件控制。
本主题依据参考截图重绘。发布包尚未代码签名，下载页提供 SHA-256 校验文件。
