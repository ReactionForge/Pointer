# 桌面预览版验证记录

版本：`1.3.0-beta.1`。本机环境：Windows 11 x64；日期：2026-10-04。

## 源码与独立审查

完整测试 80 项，79 项通过；另 1 项明确要求发布包，在构建后独立运行。系统写入在单元测试中必须替换为受控边界，真实文件与 Windows 原生资源加载仍进行实际检查。

一次完整分支独立审查发现 8 项重要问题、0 项严重问题、0 项轻微问题。对应问题均先复现失败再修复：自选安装目录识别、自定义缓存的旧安装迁移、损坏配置保护、升级后续步骤失败回退、缺失备份时阻止缓存光标卸载、首次应用全部角色尺寸、暂停恢复正常形态及保留界面草稿。

## 本机实际发布程序

- Qt APP：单实例激活、升级前安全退出通过；约 73 MB 工作集、36 MB 专用内存。
- 自定义 40 像素光标后台：应用、暂停、恢复运行、恢复原光标通过；约 29 MB 工作集、16 MB 专用内存；3 秒空闲样本约占一个核心 1.6%。这些是短时样本，随机器、场景和设置变化。
- 后台状态确认未导入 Qt；自定义资源来自持久安装数据目录。
- 测试结束后恢复测试前的实际光标，已允许的启动项及其最后写入时间不变，原光标备份 SHA-256 不变。
- 实际安装 EXE 已在独立中文/空格目录验证安装、保留配置升级、卸载和用户文件保护；最终云端构建进一步验证自选目录无覆盖参数的正常启动。

Qt 的打包启动过程原本会提前导入 QtCore。`packaging/windows/headless_runtime.py` 仅在后台 `--run` 启动时跳过这项注册，界面与诊断保持标准行为。构建依赖固定版本；[PyInstaller 官方运行时钩子说明](https://pyinstaller.org/en/latest/when-things-go-wrong.html#changing-runtime-behavior)说明自定义运行时钩子先于内置钩子执行。

## 发布与适用范围

DEV 与发布标签均执行完整测试、Windows 原生资源诊断、ZIP 安装升级准备、真实 EXE 安装升级卸载及 SHA-256 检查。GitHub Actions 保留诊断、安装日志和界面截图。

界面离屏验证覆盖 900×700 与 1100×760，测试页鼠标事件与失去焦点后的状态恢复均验证。真实物理点击的视觉手感、跨显示器效果及第三方软件自行绘制的光标，仍需要使用者在 APP「光标测试」页与实际软件中观察；不把离屏事件验证当成物理鼠标视觉验证。
