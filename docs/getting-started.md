# Pointer 使用指南

[项目首页](<../README.md>) · [支持](<../SUPPORT.md>) · [beta.6 验收记录](<releases/1.3.0-beta.6.md>)

## 下载与校验

推荐体验版本：[v1.3.0-beta.6](https://github.com/ReactionForge/Pointer/releases/tag/v1.3.0-beta.6)，支持 Windows 10/11 x64。ARM64 原生包、macOS 和 Linux 不是当前交付平台。

- EXE：安装向导，常规操作不需要管理员权限。
- ZIP：完整解压，保留所有附带目录，再运行 `Pointer.exe`。
- 两者都有对应 SHA-256 文本。请从同一发布页下载，不使用来源不明的重打包文件。

```powershell
Get-FileHash -Algorithm SHA256 .\Pointer-v1.3.0-beta.6-setup-x64.exe
```

将结果与发布页的对应校验文本比对。SHA-256 能检查文件一致性，但不替代发布者数字签名；目前 EXE 未签名。遇到 SmartScreen 提示，请先核实下载来源，不关闭 Defender，不以管理员身份绕过可疑提示。

## 第一次应用

1. 打开 **光标外观**，选造型、配色、大小；深浅预览显示当前草稿。
2. 打开 **点击动效**，选择模式，调整强度、按下时间和松开时间。数值框可直接输入并按回车；经过滑条的滚轮不会误改数值。
3. 点击底部 **应用更改**。成功后系统效果启动；第一次非内置配置可能需要等待资源生成。
4. 到 **光标测试**，在黑白背景、文本、链接和调整区域观察实际 Windows 光标。预览和测试页不是同一件事。

默认箭头最大倾斜约 6°、小手约 12°（默认强度 50）；按住保持，松开约 150 ms 回正。强度提高会改变角度，不是所有模式都采用同样形变。加载光标使用自身动画。

## 界面外观与光标草稿

**应用设置** 的浅色／深色切换只改变界面，不是光标的配色策略。

侧栏透明度与模糊独立调整，透明度分别记忆深浅主题。**保存外观** 保存窗口设置，**取消预览** 恢复已保存值；如果光标和窗口均有修改，操作条会提示保存并应用。保存失败应保留草稿，不强行继续应用。

真实背景模糊需要受支持的 Windows 11 合成环境；Windows 10、失活窗口、关闭系统透明效果、高对比等场景回退。这里不提供修改 Windows 全局效果的建议。

## 暂停、关闭与开机启动

- **暂停**：暂停效果，与开机启动选择互相独立。
- **关闭设置窗口**：后台已启用的效果可继续工作；不是卸载。
- **开机启动**：新用户默认关闭。已有用户升级保留选择；未变化启动项不重复写入。
- **恢复 Windows 原光标**：恢复最初备份。请优先使用恢复操作，而不是删除配置文件。

## 数据、升级与卸载

配置与最初备份位于 `%LOCALAPPDATA%\Pointer\data`；持久程序位于相邻 `app`。某些应用宿主可能重定向路径。不要发布整个用户数据目录，原光标备份可能含私人文件路径。

ZIP 首次成功应用会部署至持久目录；成功后可移动原解压目录。升级保留数据。beta.3 用户请手动下载安装 beta.6 一次，修复旧更新检查；后续新版可使用预发行通道。

卸载前恢复原光标。恢复失败会中止卸载，请保留程序与备份并提交脱敏诊断，不强删应用目录。

## 诊断与问题反馈

以下只读诊断命令生成报告；输出目录请先建立：

```powershell
.\Pointer.exe --diagnose --quiet --report .\pointer-diagnostics.json
```

反馈时提供版本、Windows 版本、屏幕缩放、显卡和可复现步骤。发布报告前删除用户名、私人路径与不相关机器信息。不要公开原光标备份或启动项导出。

应用自绘光标（例如部分图片抓手、游戏）可能不受系统主题影响。文本插入处闪烁的竖线是应用控制的插入符，不是鼠标 I-beam。
