## 视觉与布局方案

三种构图均使用用户确认的 Apple-inspired 视觉世界，提供真正不同的工作区组织，不改变为其他风格。

- A 分栏设置：侧栏 + 设置 + 常驻预览。推荐作为最终桌面应用结构。
- B 预览工作区：顶部导航 + 大幅预览 + 下方属性。更突出光标，但需要向下查找部分设置。
- C 紧凑设置：侧栏 + 内嵌预览 + 通栏分组。适合小窗口，预览随内容滚动。

主题使用 DESIGN.md 中的浅深语义配色。默认建议跟随系统，提供浅色/深色选择；界面主题独立于光标的深浅背景自适应策略。窗口保留真实 Windows 标题栏、缩放与键盘行为。字体使用 Windows 本机字体，不捆绑 SF Pro。

## 页面与用户流程

### 光标外观

首屏是四种现有光标形状、24/32/40/48/64 大小选择、自动/浅色/深色策略，以及当前配色。八种现有配色统一为紧凑预设区；自定义主体与描边分别按深浅背景分组。更多选项承载已有可选光晕功能，保留用户当前关闭的状态。

预览明确标为“草稿预览”，展示浅色底黑主体白描边、深色底白主体黑描边。保留箭头、小手、输入、等待、后台加载角色；放大的预览与实际配置尺寸分别标明。

### 左键动效

六种已有动效用简短名称与一致选中态呈现。强度、按下时间、松开时间使用带数值的控件，数值始终可读，并可通过键盘调整。关闭动效后禁用相关参数，并保留值。预览中可按住和松开模拟；没有假称预览已验证系统光标。

### 光标测试

用场景导航组织深浅适配、点击反馈、文字输入、链接与拖动、等待/后台加载、其他角色。保留全部真实 Windows 共享光标句柄测试。显示当前已应用状态、点击计数和实际按下/松开状态，不能把收到点击事件当成视觉验证成功。退出加载场景、离开页面、失焦时清理等待与按下状态。

### 应用设置

按运行与启动、辅助功能、配置备份、软件更新、系统恢复组织。使用短标签和必要说明，单行控件不足时换成垂直布局。开机启动仍是独立即时操作；导入先进入草稿；导出保留原格式；恢复原光标仍需要明确确认并保留备份。更新弹窗使用同一颜色与字体系统，展示真实版本、下载进度、取消和失败重试。

### 公共反馈

固定操作区显示“草稿修改”“已应用”“处理中”或“失败”，附明确的主操作。尚未启用光标时允许应用当前配置。忙碌时禁用重复提交；失败保留草稿并提供可读原因。普通成功反馈短暂显示，错误同时保留在可访问的文本区域，不只靠颜色或自动消失的消息。

退出有未应用修改时沿用确认流程。关闭设置窗口与停止后台服务保持独立。托盘菜单使用同一功能名称。开发测试网页只同步视觉令牌、场景导航与反馈，不改变系统测试的事实边界。

## 交互细节与可访问性

界面按钮按下反馈约 100–140 ms，开关过渡约 140–180 ms，提示淡出约 160–200 ms。高频导航、键盘操作与参数显示立即响应，不添加页面入场动画。快速连续操作从当前状态转向新状态，避免动画完成回调误隐藏新提示。

保持 Tab/Shift+Tab 顺序、按钮 Space/Enter、选择器方向键和 Esc 关闭可取消弹窗。设置行和图标按钮提供可访问名称。文字对比度以常规文字 4.5:1 为目标；必要控件与焦点边界清楚；选中项同时有形状或勾选标记。减少界面动效设置只影响 UI，不能覆盖用户明确配置的光标动效。

1180×800 为参考画布。880×620 与更小可用工作区采用单列控件与可滚动内容；预览折叠为可展开区域，避免挤压设置。125%、150%、200% DPI 使用 Qt 实际字体度量与逻辑尺寸，不能靠缩小文字适配。

## 实现组织提案

沿用现有四页与应用层边界。将令牌/样式留在 ui/theme.py，公共控件整理到 ui/components/，统一图标在 ui/icons.py，UI 主题与减少动效等视图偏好在 ui/view_preferences.py 管理；此偏好独立存储，不破坏严格校验的光标配置 JSON。预览继续调用唯一的 cursor/art 绘制实现。UI 页面不接触注册表。是否进一步抽出草稿控制器以降低 main_window.py 复杂度，在正式实施计划中按实际依赖决定。

PRODUCT.md 记录产品事实，DESIGN.md 记录设计方向，本文件记录任务范围。设计图保存在 docs/images/，临时生成器和本机检查数据放 .local/，Impeccable 工具状态不提交。
