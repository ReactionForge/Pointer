# 澄层 · 空间的回应

空间应当具有重心和节奏。一个明确的主体与几处较轻的回应形成张力，视线在宽阔和紧密的区域之间流动。对称不是秩序的唯一来源；经过精心推敲的不对称同样稳定，并给观察留下探索的余地。每一处空白都由专业工艺校准，让布局拥有方向而无需装饰说明。

形状从其关系中获得生命。熟悉的轮廓可以放大成为焦点，也可以退后成为陪衬；不同尺度让同一套语言出现丰富的节拍。主体始终清楚，配角不争抢，画面像经过顶尖设计者反复打磨的整体。变化应当让人更容易理解对象，而不是让对象变得陌生。

材质说明人与内容之间的距离。透明的工具靠近操作，稳定的表面承载阅读和观察；高光、边缘和阴影只在关系需要时出现。黑白保持坚实的中心，色彩来自必要的功能与真实内容。精湛工艺让材质轻而不虚、丰富而不浑浊。

布局可以回应动作。选择让焦点转移，拖动让边界跟随，按住让轮廓表达力量；释放后，空间重新安定。所有变化都能被接续和撤回，细节由经验与耐心打磨得自然可靠。静止时没有催促，动作时没有迟疑。

文字以最少的词语准确定位。字重、基线与留白参与构图，说明在需要处出现，操作的位置在变化中保持可辨认。真正的创造力不是摆脱使用者的习惯，而是在熟悉的路径上给予新的观察方式，使每一次接触都清晰、有力并经过深思熟虑。
