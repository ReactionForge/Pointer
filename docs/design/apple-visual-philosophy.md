# 澄层 · Liquid Focus

空间以澄澈的层次建立秩序。内容拥有完整、安静的平面，功能以轻盈的材质悬于其上；两者的距离可以被看见，却不需要被解释。留白不是空缺，而是经过反复衡量的视线通道。每一处边缘和间隔，都应有经验丰富的设计者仔细推敲后的自然感。

透明是一种结构语言。光从边缘轻轻折入，色彩仅在必要处渗透，明暗变化说明前后关系。玻璃的存在必须服务于层次和操作；文字所在的区域始终稳定清晰。精湛的制作体现在克制的高光、准确的阴影方向与几乎不可察觉的光学修正中。

黑与白构成明确的重心。一个小而熟悉的轮廓，在广阔的表面上获得足够的关注；形状不被体积、辉光或装饰替代。局部的丰富来自轮廓、比例、反差和尺度之间的关系。精细工艺让最简单的形状也经得起放大，而实际尺度仍然易于辨认。

文字是操作的坐标。短标签、清晰数值和适当的字重建立阅读节奏，说明只在需要时出现。形状、材质和空间先传达信息，文字再精确确认。每一行的基线、每一组控件的间距和每一个圆角都应经过耐心校准，体现顶尖工艺，而不依赖夸张表达。

运动延续人的动作。按下带来轻微压缩，选择留下连续的位置关系，拖动没有延迟，反馈在原处完成。动作可以随时被新的意图接续，不把人困在表演里。精湛的交互准确而安静：每一处都让使用者确信自己的操作已被理解。
