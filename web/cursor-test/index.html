小手不只有一种。

上方系统卡片的“链接小手”会使用你的 Windows 方案。这里图片上的张开手掌和按住后的握拳手掌，则由浏览器提供，外观可能不同。

  • 移入图片：张开手掌 grab
  • 按住拖动：握住手掌 grabbing
  • 移到缩放按钮：浏览器的放大镜光标

Windows「照片」也有自己的拖动手掌；它保留原样，不代表整套系统光标失效。
