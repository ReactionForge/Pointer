Pointer — Windows 黑白自适应光标

浅色背景：黑色主体、白色边框。
深色背景：白色主体、黑色边框。
圆角造型，无蓝光；17 种 Windows 系统光标，保留加载动画。

安装
1. 完整解压 ZIP，打开 Pointer 文件夹。
2. 双击“一键安装.cmd”或“install.cmd”。
3. 等待安装完成提示；光标将自动启用并随当前用户登录启动。

DEV 开发版 1.2.0：默认按下左键时箭头和链接小手顺时针倾斜约 12°，长按保持，松开约 150 毫秒回正。
原来的缩小回弹保留为独立模式。双击“使用缩小回弹.cmd”或“使用倾斜动效.cmd”切换；开始菜单 Pointer 中也有相同入口。
选择会保留到下次登录和升级。两种模式各自生效，不叠加。
深浅两套配色均适配，点击热点固定。可在测试页的“点击动效”区域检查。

适用于 Windows 10/11 x64。不需要安装 Python，不需要管理员权限，安装和使用无需联网。
程序安装在 %LOCALAPPDATA%\Pointer\app。
原光标设置及运行数据保存在 %LOCALAPPDATA%\Pointer\data。
安装成功后可删除下载的 ZIP 和解压文件夹；请保留已安装的 app 和 data 目录。

日常操作
安装后打开开始菜单 → Pointer：
- 启用自适应光标：启用自动切换和登录启动。
- 停止自动切换：关闭后台程序及登录启动，保留黑主体、白边框固定配色。
- 恢复原光标：恢复安装前保存的光标设置，并关闭后台程序及登录启动。
- 打开测试页：离线测试各种光标和深浅背景。

更新时，下载新版本并再次运行“一键安装.cmd”；已有原始设置备份会保留。
移除时，请先“恢复原光标”，再删除 app 目录和开始菜单的 Pointer 文件夹。
data 目录可以保留，便于以后恢复原始设置。

说明
后台程序在本机检测背景亮度，整只光标一起切换颜色，不上传屏幕内容。
中灰背景保留上一次的配色，以减少频繁切换。
Windows“照片”的拖动手掌和部分应用自绘光标可能不使用系统光标方案。
发布包未进行代码签名，Windows 可能提示来源或信誉未知。请核对官方仓库的发布来源及 SHA-256 校验值；无需关闭安全软件。
